## Що створиться після навчання

- `model/mnist_cnn.pt` — **ваги навченої CNN**, завантажуються у вебзастосунок;
- `results/learning_curves.png` — криві точності й втрат під час навчання;
- `results/misclassified_digits.png` — приклади помилкових прогнозів;
- `results/noise_experiment.png` — приклади оригінальних і зашумлених цифр;
- `results/metrics.json` — фактична точність моделі на тестових цифрах і в експерименті зі спотворенням;
- `results/history.json` — метрики за епохами.

**Не копіюй чужі цифри точності у звіт:** візьми свої результати з `results/metrics.json`.

## Що досліджується

1. Архітектура **Conv2D(16) → MaxPool → Conv2D(32) → MaxPool → Dense(64) → Dense(10)**.
2. Навчання мережі на MNIST; окремі train/validation/test вибірки — 55 000 / 5 000 / 10 000.
3. Правильні й помилкові прогнози тестового набору.
4. Один невеликий додатковий експеримент: до **1 000** тестових цифр додається гаусовий шум (σ = 0.25), вимірюється зміна точності. Навчання на зашумлених зображеннях не виконується.
5. Інтерактивний застосунок: користувач малює цифру, модель класифікує її й показує ймовірності для 0–9 та нормалізоване зображення 28×28.

На вебсторінці натисни **«Очистити»** (або `Esc`) перед новою цифрою, **«Розпізнати»** — кнопка або `Enter`. Спробуй намалювати одну цифру незвичайним почерком: модель може помилитися. Це нормальний експеримент для ЛР5.

## Фронтенд (React)

Інтерфейс написано на **React + Vite** у теці `frontend/`. Готова збірка лежить у `static/` і віддається FastAPI, тому для звичайного запуску Node.js **не потрібен** — достатньо `uvicorn`.

Якщо змінюєш інтерфейс:

```bash
# Можна запускати прямо з кореня проєкту:
npm run build   # перезбирає static/
npm run dev     # режим розробки Vite
npm run lint    # перевірка ESLint

# Або з теки frontend:
cd frontend
npm install
npm run dev     # http://localhost:5173, запити /status і /predict проксіюються на uvicorn :8000
npm run build   # перезбирає static/
```

## Структура

```text
digit-cnn-lab5/
├── train.py                # навчання CNN, оцінка, графіки
├── network.py              # архітектура CNN
├── image_processing.py     # нормалізація намальованих цифр
├── app.py                  # FastAPI: вебсервер + прогноз
├── frontend/               # вихідний код інтерфейсу (React + Vite)
│   └── src/
│       ├── App.jsx                     # стан застосунку, кнопки, клавіші
│       ├── api.js                      # запити /status і /predict
│       ├── hooks/useModelStatus.js     # перевірка готовності моделі
│       ├── components/DrawingCanvas.jsx
│       ├── components/ResultPanel.jsx
│       ├── components/ProbabilityList.jsx
│       ├── components/StatusBadge.jsx
│       └── styles.css
├── static/                 # збірка фронтенду (генерується `npm run build`)
├── model/                  # сюди збережуться ваги
└── results/                # сюди збережуться графіки
```

- Вхід: один канал **28×28**. Вихід: десять значень softmax для цифр **0–9**.
- `Conv2D` виділяє локальні ознаки; `MaxPool` зменшує карти ознак; `Dense` класифікує.
- Функція втрат: `CrossEntropyLoss`, оптимізатор: Adam.
- Зображення з браузера відрізняється від стандартного MNIST: застосунок обрізає порожні поля, масштабує цифру до рамки 20×20 і центрує її в 28×28.
- Softmax «впевненість» — не гарантія правильного розпізнавання.
- Остаточна тестова вибірка не використовується як `validation_data` під час навчання.

Якщо сервер запущено **до** навчання моделі, вебсторінка покаже повідомлення, а не видаватиме випадкові прогнози. Після створення `model/mnist_cnn.pt` онови сторінку.
